# 検証記録

## v0.2.0 Web 版 — 2026-10-27

実行環境: Linux x86_64（4 コア）、Node.js 22.22.0、Playwright の Chromium（ヘッドレス）。Windows 実機の Chrome / Edge では未検証です。

| 検証 | 結果 |
| --- | --- |
| `npm test` | 31 テスト成功（編集ロジック、書き出しコマンドの組み立て、録画・クリップ・注釈の画面操作） |
| `npm run build` | 型チェックと本番ビルド成功 |
| 動画追加 → 注釈（テキスト・ぼかし）→ MP4 書き出し | 成功。720p・音声あり MP4（4 秒）と 800×600・25fps・音声なし WebM（3 秒）から、1920×1080・30fps・H.264 / AAC 48kHz・7.0 秒の MP4 を出力（ffprobe で確認） |
| 書き出し時間 | 上記 7 秒の動画で約 39 秒（x264 superfast）。同じ環境のネイティブ FFmpeg（シングルスレッド）の約 5 倍 |
| 書き出しのキャンセル → 再書き出し | 成功 |
| 画面録画（Chromium の疑似画面・疑似マイク） | 成功。一時停止中の時間を除いた長さで取り込み、音声ありと判定 |
| 再読み込み後の自動保存の復旧 | 成功。復旧した動画をプレビューで再生可能 |
| Content Security Policy の下での動作 | 本番ビルド（CSP あり）と開発サーバーの両方で、上記の書き出しが成功 |

### 補足

- ヘッドレス Chromium は MP4 形式の録画に対応していないため、WebM 形式で録画される経路のみ確認しました。Windows の Chrome / Edge では MP4 形式で録画されます。
- ffmpeg.wasm のマルチスレッド版は、書き出し中に「function signature mismatch」で停止したため採用していません。
- 実際の画面共有ダイアログ、PC 内部音声、「最前面に表示」の操作バーは、ヘッドレス環境では確認できません。

デスクトップ版（v0.1.x）の検証記録は Git 履歴を参照してください。
