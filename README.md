# Operation Video Studio

操作画面を録画し、カット・並べ替え・注釈を加えて MP4 に書き出す Web アプリです。インストールは不要で、Windows の Chrome / Edge で開いて使います。動画の録画・編集・書き出しはすべてブラウザ内で処理し、動画をサーバーへ送信しません。

## 機能

- 画面録画：ブラウザの画面共有で、画面全体・ウィンドウ・タブを録画。3 秒のカウントダウン、一時停止・再開、停止で自動取り込み
- 音声：マイク、PC 内部音声（共有時に「システム音声も共有する」を選択）、両方の同時録音
- 録画中の操作バー：ページ上部に表示。Chrome / Edge では「最前面に表示」で、他のアプリの上に小さなウィンドウで表示
- 動画の追加：ファイル選択、またはドラッグ＆ドロップ（MP4 / WebM / MOV / MKV など）
- 編集：分割、クリップ削除、区間削除、並べ替え（ドラッグ／左右ボタン）、Undo / Redo、タイムラインの拡大縮小、クリップ名の変更
- 注釈：テキスト・矢印・四角形・円・番号・ハイライト・ぼかし・モザイク（表示時間つき）
- 音声編集：クリップごとの音量・消音、素材の音声だけを別トラックに追加
- 黒画面・無音の挿入
- 書き出し：MP4（H.264 / AAC）、1080p / 720p / 先頭動画の解像度、30fps、進捗表示とキャンセル
- プロジェクト：JSON で保存・再読み込み。編集中の内容はブラウザ内（IndexedDB）に自動保存し、次回起動時に復旧を提案

## 動作環境

- Windows 10 / 11 の Google Chrome または Microsoft Edge（最新版）
- 録画は `getDisplayMedia` と `MediaRecorder` に対応したブラウザが必要です。Firefox / Safari では録画以外の機能のみ使えます。
- 書き出しは ffmpeg.wasm（ブラウザ内で動く FFmpeg）を使います。シングルスレッドで動くため、書き出しには動画の長さの数倍の時間がかかります。

## 開発

```bash
npm ci
npm test         # 単体テスト・画面テスト（Vitest）
npm run dev      # 開発サーバー http://127.0.0.1:1420
npm run build    # 本番ビルド（dist/）
npm run preview  # 本番ビルドの確認
```

Node.js 22 以上が必要です。GitHub Actions で `npm test` と `npm run build` を実行します。

## Vercel への公開

リポジトリを Vercel にインポートすると、`vercel.json` の設定（`npm ci` → `npm run build` → `dist/` を配信）でそのまま公開できます。環境変数やサーバー側の処理はありません。

## 構成

- `src/App.tsx`, `src/AnnotationEditor.tsx`, `src/AudioTrack.tsx`, `src/style.css`: 編集画面（React / TypeScript / Tailwind）
- `src/editor.ts`: 元動画の参照と in/out 点を持つ非破壊タイムライン
- `src/annotations.ts`: 注釈の描画（プレビューと書き出しで共通の Canvas 描画）
- `src/recorder.ts`: 画面共有・マイクの取得、音声の合成、`MediaRecorder` による録画
- `src/platform.ts`: 動画ファイルの読み込み、IndexedDB への自動保存・復旧、プロジェクトの保存・読み込み、書き出しファイルの保存
- `src/exporter.ts`: 書き出し用の FFmpeg コマンド（切り出し・正規化・連結・音声合成・注釈の焼き込みを 1 回のエンコードで実行）
- `src/ffmpeg.ts`: ffmpeg.wasm の読み込み・実行・動画情報の解析
- `tests/`: 編集ロジック・書き出しコマンド・画面操作のテスト
- `docs/software-approval-request.md`: 社内の利用申請用の説明資料

## 安全性と制約

- 動画はブラウザの外へ送信しません。本番ビルドには、自サイト以外への通信を禁止する Content Security Policy（`connect-src 'self'`）を埋め込んでいます。ffmpeg.wasm 本体も自サイトから配信し、外部 CDN は使いません。
- 録画・追加した動画はブラウザの IndexedDB に保存されます（自動保存・復旧のため）。ブラウザのサイトデータを削除すると消えます。
- 元の動画ファイルは変更しません。書き出しは新しいファイルとして保存します（Chrome / Edge では保存先を選択、その他のブラウザではダウンロード）。
- プロジェクトファイル（JSON）には動画そのものは含まれません。別のブラウザ・PC で開くときは、プロジェクトファイルと一緒に使用している動画ファイルも選択してください。
- 書き出しは PC のメモリを使います。長時間・高解像度の動画では、メモリ不足で失敗する場合があります。
- ぼかしはプレビューの CSS と書き出しの FFmpeg で実装が異なるため、見た目は完全一致しません。機密情報の隠蔽には十分な範囲を指定し、書き出し結果を確認してください。
- クリック位置の強調、マウスで指定した範囲の録画は、ブラウザの制約により Web 版では使えません（デスクトップ版で作成したクリック記録は書き出しに反映されます）。

FFmpeg（ffmpeg.wasm）のライセンスについては [ライセンス方針](docs/ffmpeg-license.md) を参照してください。検証結果は [検証記録](docs/validation.md) を参照してください。
