# 実装状況と残る検証

Phase 1〜3の機能コードはローカル作業ツリーへ実装済みです。GitHubへの公開・配布済みアプリへの反映はしていません。

## Phase 1

WindowsネイティブGDI録画、対象選択、カウントダウン、一時停止/再開、素材取込、非破壊カット/連結、MP4正規化出力、キャンセルを実装。領域選択ウィンドウは非同期作成、ウィンドウ対象はHWNDで識別します。

## Phase 2

時間付き注釈をJSON version 2で管理。テキスト/矢印/四角/円/番号/ハイライトを共通Canvasで描画し、透過PNGをFFmpegで焼き込みます。プレビュー位置移動、プロパティ、別トラックの端ドラッグ、複製/削除を実装。

## Phase 3

Undo/Redo、ショートカット、保存/再編集、二世代の復旧スナップショット、WASAPIマイク/ループバック、クリック強調、ぼかし/モザイク、黒画面/無音、クリップ音量、独立音声、プレビュー用変換、録画名/保存先記憶、並べ替えボタンを実装。Windowsアプリアイコンと画面内ロゴも統一。

## 完了判定に必要な作業

Linuxでは編集ロジック・実際のFFmpeg処理・Windows向け型チェックを行います。Windows実行環境がないため、ネイティブ録画と音声同期、長時間録画、DPI、WebView2操作、インストーラー生成/更新は未検証です。全9項目の試験はdocs/windows.mdの手順で実機確認が必要です。

署名済み配布、FFmpeg同梱、Windows Graphics Captureへの移行は実装していません。現在はFFmpegを利用者がローカルに用意する方式です。ぼかしのプレビューと書き出しは異なる処理で完全一致しません。
