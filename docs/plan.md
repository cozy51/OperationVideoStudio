# 段階的実装計画

## Phase 1 — 基本録画と編集

1. React / Vite / TypeScript / Tailwind と Tauri v2 を初期化。
2. 動画参照とクリップの source in/out を独立させる。元動画を変更しない。
3. Rust の FFprobe で素材情報を取得し、ネイティブ選択したファイルのみ読めるようにする。
4. Windows API でモニター・ウィンドウを列挙。FFmpeg gdigrab で直接ディスクに録画。
5. 別ウィンドウの録画ツールバーとマウス領域選択。一時停止をセグメント化して保存。
6. プレビュー、分割・範囲削除・並べ替え、複数素材追加。
7. 素材を解像度・30fps・H.264/AAC に正規化して連結。キャンセルと上書き禁止。
8. Windows CI で exe/msi を生成し、実機で録画→5秒削除→追加→MP4再生を検証。

Undo/Redo とプロジェクト JSON / 復旧は編集基盤に必要なため先行実装。

## Phase 2 — 注釈

- version 2 JSON に別トラックの時間付き注釈を追加。型は text / arrow / rectangle / ellipse。
- 正規化座標でプレビューと出力の配置を統一し、ドラッグ移動と表示時間を編集。
- 日本語フォントを含む注釈を透過画像に描画し、同じ画像をプレビューと FFmpeg overlay で共有。
- overlay の enable 時間は編集後の時刻。解像度変更時の倍率・フォント・枠線の一致を画像比較で検証。
- 完了条件の「ここをクリック」・赤枠の焼き込みはこの段階の受入試験。

## Phase 3 — 操作性・音声・安定性

- WASAPI loopback とマイクを共有タイムスタンプで取得し、映像と同期。ブラウザ録画へ置き換えない。
- GDI 録画の制約を調査し、必要に応じて Windows Graphics Capture に移行。
- クリック強調、音声の独立トラック、番号・ハイライト、ぼかし・モザイク。
- 黒画面/無音挿入、注釈タイムラインの複製・端ドラッグ、フレーム精度のシームレスプレビュー。
- 長時間録画、混在 DPI、最小化・対象終了、空き容量不足、異常終了、キャンセル、復旧試験。
- インストーラーの署名と FFmpeg 配布方法を確定。

## Phase 1 の受入範囲

Linux 自動試験は編集ロジックと FFmpeg パイプラインを検証する。Windows の録画API・WebView2・インストーラーは実機で検証する。注釈を含む全9項目の完了条件は Phase 2 が終わるまで未完了。
