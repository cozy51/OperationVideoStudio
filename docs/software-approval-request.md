## 2. 機能

ブラウザで PC 画面の操作を録画し、ブラウザ内で編集して MP4 で保存する Web アプリです。

- 画面録画：ブラウザの画面共有機能を使用。録画する画面・ウィンドウ・タブは、ブラウザが表示する選択画面で利用者が毎回選びます。
- 音声録音：マイク、PC 内部の音声（いずれも利用者が選んだときだけ）
- 動画編集：分割、削除、並べ替え、テキスト・矢印・枠などの注釈、ぼかし・モザイク
- 書き出し：MP4（H.264 / AAC）形式で、利用者が指定した場所に保存

録画中は、ブラウザ自身が「共有中」の表示を出します。利用者の操作なしに録画が始まることや、ページを閉じた後に録画が続くことはありません（ブラウザの仕様による）。

## 3. ネットワーク通信

**録画・編集した動画は、サーバーにも外部にも送信しません。** 録画・編集・書き出しはすべて利用者のブラウザ内で行います。

| 通信 | 内容 |
| --- | --- |
| ページを開いたとき | Vercel から画面のプログラム（HTML / JavaScript / CSS）と動画処理エンジン（ffmpeg.wasm、約 32MB）を読み込む |
| それ以外 | なし（動画のアップロード、利用状況の送信、外部 API の利用はない） |

- ページには Content Security Policy（`connect-src 'self'` など）を設定し、配信元のサイト以外への通信をブラウザが禁止するようにしています。
- 動画処理エンジンも同じサイトから配信し、外部 CDN は使いません。
- サーバー側のプログラム・データベースはありません（静的ファイルの配信のみ）。

## 4. 取り扱うデータと保存先

すべて利用者の PC 内に保存されます。

| データ | 保存先 | 備考 |
| --- | --- | --- |
| 録画した動画・追加した動画 | ブラウザ内の保存領域（IndexedDB） | 自動保存・復旧のため。ブラウザのサイトデータ削除で消える |
| 編集中の内容（自動保存） | 同上 | 次回開いたときに復旧を提案 |
| 書き出した MP4 | 利用者が選んだ場所 | 保存時に保存先を選択 |
| プロジェクトファイル（JSON） | 利用者が選んだ場所 | 編集内容と動画のファイル名を記録。動画そのものは含まない |

- 元の動画ファイルは読み取りのみで、変更・削除しません。
- 録画には画面に表示された内容がすべて写るため、機密情報・個人情報が映る画面の録画には注意が必要です。社内の情報取扱規程に従って運用します。【記入：保存先や共有方法の運用ルールがあれば】

## 5. ブラウザの機能の利用（権限）

| 機能 | 用途 | 動作する条件 |
| --- | --- | --- |
| 画面共有（`getDisplayMedia`） | 画面の録画 | 「録画開始」を押し、ブラウザの選択画面で利用者が共有対象を選んだときのみ |
| マイク（`getUserMedia`） | マイク音声の録音 | 利用者がマイク録音を選び、ブラウザの許可画面で許可したときのみ |
| ファイルの選択・保存 | 動画の追加、プロジェクト・MP4 の保存 | 利用者がダイアログで選んだファイル・保存先のみ |
| IndexedDB | 自動保存・復旧 | 常時（このサイト専用の保存領域） |
| ピクチャー・イン・ピクチャー | 録画中の操作バーを最前面に表示 | 利用者が「最前面に表示」を押したときのみ |

- カメラ・位置情報は使用しません（`Permissions-Policy` で無効化）。
- キーボード入力やクリックの記録、ほかのアプリの操作の監視は行いません。

## 7. 利用開始・終了

- 利用開始：Chrome / Edge で公開 URL を開くだけです。インストールは不要です。
- 利用終了：ブラウザの設定から、このサイトのデータ（IndexedDB）を削除すると、ブラウザ内に保存された動画・編集内容が消去されます。書き出した MP4 とプロジェクトファイルは、利用者が保存した場所に残ります。
