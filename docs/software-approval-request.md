## 2. ソフトウェアの機能

PC 画面の操作を録画し、録画した動画を PC 上で編集して MP4 で保存するソフトウェアです。

- 画面録画：デスクトップ全体、モニター、指定ウィンドウ、マウスで選んだ範囲
- 音声録音：既定のマイク、PC 内部の音声（いずれも利用者が選んだときだけ）
- 動画編集：分割、削除、並べ替え、テキスト・矢印・枠などの注釈、ぼかし・モザイク
- 書き出し：MP4（H.264 / AAC）形式で、利用者が指定したフォルダーに保存

録画は利用者が録画ボタンを押し、3 秒のカウントダウンの後に始まります。録画中は画面上にツールバーと録画範囲の赤枠が表示されます。バックグラウンドで自動的に録画・常駐する機能はありません。

## 3. ネットワーク通信

**外部への通信は行いません。**

- インターネット・社内サーバーへの通信機能はありません（HTTP 通信ライブラリ、自動アップデート機能、利用状況の送信機能を含みません）。
- 画面表示部分（WebView2）は、コンテンツセキュリティポリシー（CSP）で外部サイトへの接続を禁止しています。接続先はアプリ内部の通信（`ipc:` / `asset:`）のみです。
- 外部の AI・クラウド API は使用しません。動画の処理はすべて PC 内で行います。

## 4. 取り扱うデータと保存先

| データ | 保存先 | 備考 |
| --- | --- | --- |
| 録画した動画・音声 | 利用者が選んだフォルダー | 録画前に毎回保存先を確認 |
| 書き出した MP4 | 利用者が選んだ場所 | 同名ファイルは上書きしない |
| プロジェクトファイル（JSON） | 利用者が選んだ場所 | 編集内容と元動画のパスを記録 |
| 自動保存データ・プレビュー用の一時動画 | `%LOCALAPPDATA%\jp.operationvideostudio.desktop\` | アプリの設定・復旧用 |
| 設定（録画の保存先、FFmpeg の場所） | 同上 | JSON ファイル |

- 録画した内容は PC 内にのみ保存され、外部に送信されません。
- 元の動画ファイルは読み取りのみで、変更・削除しません。
- 録画には画面に表示された内容がすべて写るため、機密情報・個人情報が映る画面の録画には注意が必要です。社内の情報取扱規程に従って運用します。【記入：保存先や共有方法の運用ルールがあれば】

## 5. OS の機能の利用（権限）

実行に管理者権限は不要です。通常のユーザー権限で動作します。利用する Windows の機能は次のとおりです。

| 機能 | 用途 | 動作する条件 |
| --- | --- | --- |
| 画面キャプチャ（GDI） | 画面の録画 | 録画中のみ |
| ウィンドウ一覧の取得 | 録画するウィンドウの選択肢を表示 | 録画対象を選ぶとき |
| 音声入力・出力（WASAPI） | マイク・PC 内部音声の録音 | 録画中で、利用者が録音を有効にしたときのみ |
| マウス左ボタンの状態・カーソル位置の取得 | 録画動画でクリック位置を強調表示 | 録画中のみ。録画範囲内のクリック位置と時刻だけを記録。キーボード入力は記録しない |
| ウィンドウを画面キャプチャから除外する設定 | アプリ自身の録画ツールバー・赤枠が動画に写り込まないようにする | 録画中のみ。対象はこのアプリのウィンドウだけ |
| 外部プログラム（FFmpeg）の起動 | 録画・動画変換 | 録画・書き出し時。コンソール画面を表示せずに起動 |

- 画面表示部分（JavaScript）には、ファイル操作・コマンド実行・HTTP 通信の権限を与えていません。ファイルへのアクセスは、利用者がダイアログやドラッグ＆ドロップで選んだ動画に限定しています。
- レジストリの書き換え、常駐（スタートアップ登録）、サービス登録は行いません。

## 7. インストール・アンインストール

- インストーラー：NSIS（.exe）または MSI 形式。デジタル署名は未付与です。
- インストール先：NSIS 版は既定でユーザー単位（`%LOCALAPPDATA%` 配下、管理者権限不要）、MSI 版は PC 単位（`Program Files` 配下、インストール時に管理者権限が必要）
- アンインストール：Windows の「設定 → アプリ」から削除できます。`%LOCALAPPDATA%\jp.operationvideostudio.desktop\` の設定・一時データは手動で削除できます。録画・書き出した動画は利用者のフォルダーに残ります。
