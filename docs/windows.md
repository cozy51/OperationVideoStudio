# Windows 開発と実機検証

## 必要な環境

- Windows 10 **2004 以降** または Windows 11（録画ツールバー除外APIの要件）。64bit。
- Node.js 22 以上と npm。
- Visual Studio 2022 Build Tools: 「C++ によるデスクトップ開発」、Windows SDK。
- Rust stable / `x86_64-pc-windows-msvc`。
- Microsoft Edge WebView2 Runtime。
- `ffmpeg.exe` と `ffprobe.exe` を PATH に配置。gdigrab と libx264 / AAC 対応ビルド。ローカル修正版のHWND指定にはFFmpeg 7.1以降を使用。

FFmpeg は公式サイトの Windows ビルド案内から入手し、配布元のチェックサム/署名で検証してください。TLS やチェックサム検証を無効にしないでください。本プロジェクトはバイナリを自動ダウンロード・同梱しません。

```powershell
node --version
rustc --version
ffmpeg -hide_banner -devices
ffmpeg -hide_banner -encoders
ffprobe -version
npm ci
npm test
cargo test --manifest-path src-tauri/Cargo.toml --no-default-features --locked
npm run tauri dev
```

起動後、「録画」で対象・カーソル・画質を選び、保存先を指定。3秒後にメイン画面が最小化され、除外設定済みのツールバーから一時停止/再開/停止できます。ウィンドウ録画は対象を最小化しないでください。公開済みv0.1.2ではタイトルで対象を検索するため、タイトル変更により録画開始に失敗する場合があります。未公開のローカル修正版はHWNDと所有プロセスを照合し、タイトル検索を使用しません。公開版でこのエラーが出る場合はモニターか範囲録画を使ってください。

録画映像にツールバーが映り込まないか実機で必ず確認してください。保護コンテンツ・UAC のセキュアデスクトップ・アプリ固有の描画方式は録画できない場合があります。

## 「program not found」で録画できない場合

FFmpeg がアプリから見つからない状態です。インストーラーにはFFmpegを同梱していません。

1. 信頼するWindows用FFmpegビルドを導入し、`ffmpeg.exe` と `ffprobe.exe` を用意してください。wingetを使う場合は次のコマンドで導入できます。

   ```powershell
   winget install --id Gyan.FFmpeg --exact
   ```

2. v0.1.1以降は「録画」→「FFmpegのフォルダーを設定」で、両方のexeがある `bin` フォルダーを選択できます。選択したフォルダーはアプリ設定に保存され、次回起動にも使用します。
3. 「FFmpeg / FFprobe・Windows録画を使用できます」が表示されてから録画を開始してください。
4. PATHに追加して使う場合は、アプリを完全に終了して起動し直してください。古い起動プロセスにはPATH変更が反映されません。

録画前にFFmpeg/FFprobe・gdigrab・libx264/AACを検査します。未導入時は保存先選択やカウントダウンに進みません。フォルダー内のプログラムを実行するため、配布元・チェックサムを確認したものを選択してください。

## インストーラー

```powershell
npm run tauri build
```

`src-tauri/target/release/bundle/nsis/*.exe` と `src-tauri/target/release/bundle/msi/*.msi` に生成されます。Windows CI も同じコマンドを実行します。生成設定を追加した段階で、クラウドから CI を実行・成果物を公開したわけではありません。FFmpeg は利用者が別途導入します。

## ウィンドウ指定のローカル修正版の実機確認項目

GitHubには未反映。Windows実機で次を確認してください。

- SOLIDWORKSを選択後、ファイルを開いてタイトルを変更してから録画開始。
- 一時停止中にタイトルを変更しても同じウィンドウを再開できる。
- 同じタイトルの別ウィンドウを開いても、選択したHWNDを録画する。
- 対象を閉じる・最小化した場合は日本語のエラーを表示し、別の対象を録画しない。
- SOLIDWORKSの描画が黒画面にならないか出力を確認。GDIと描画方式の相性はタイトル検索とは別の検証項目。

## 未公開ローカル版：録画名・保存先・クリップ操作

- 新しい録画は選択した保存先の `Rec_01/Rec_01.mp4`、`Rec_02/Rec_02.mp4` に保存。既存のRec番号に続く番号を使い、既存ファイル・フォルダーは上書きしない。失敗した録画フォルダーも残すため欠番になる場合がある。過去のOVSフォルダーを自動で移動・改名しない。
- 録画設定画面に前回の保存先を表示し、再起動後も使う。「保存先を変更」で変更可能。保存先が削除された場合は選択し直す。
- 下部の映像クリップにある「⋮⋮」をつかみ、移動先のクリップの上で離す。青い枠が移動先。クリックで選択して「左へ移動」「右へ移動」を使う方法もある。
- 選択中のクリップの右側「クリップ名」で表示名を入力し、Enterまたは欄の外のクリックで確定。クリップごとに名前を付けられ、Undo/RedoとJSON保存に対応。元動画の名前・パスは変えない。

Windowsで保存先の再起動復元、連続録画、ネイティブ選択ダイアログ、クリップのドラッグ操作を実機確認すること。この機能はGitHub・公開インストーラーには未反映。

## 未公開ローカル版：対象の除外と赤枠確認

- 録画対象の列挙で最小化されたウィンドウ（IsIconic）を除外。
- 対象を選択すると、デスクトップ・モニター・ウィンドウのクライアント領域・選択範囲を赤枠で示す。ウィンドウの移動・サイズ変更には約1秒間隔で追従。
- 枠はクリックを透過し、フォーカスを取らない。WebViewの準備後に表示し、録画除外を設定。録画開始前・設定画面を閉じたときに破棄する。
- 選択したウィンドウが最小化・終了されたら一覧から外し、選択を解除する。別の対象へ自動で切り替えない。「対象一覧を更新」でも更新可能。

Windowsで赤枠の位置（混在DPI含む）、マウス操作透過、対象移動・最小化、設定キャンセル、録画に枠が映らないことを確認する。これらのネイティブ動作は実機未検証。

## 未公開ローカル版：素材一覧のクリック操作

左側の動画一覧は、クリックで元動画を先頭からプレビュー再生し、ダブルクリックでタイムライン末尾に1本追加する。素材確認中は「素材確認：ファイル名」と表示し、「編集結果へ戻る」で編集画面の再生位置へ戻る。素材の確認はプロジェクトやUndo履歴を変更しない。
