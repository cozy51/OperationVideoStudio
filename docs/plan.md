# 実装状況と残る検証

v0.2.0 で、Windows デスクトップアプリ（Tauri / Rust）から Web アプリに置き換えました。デスクトップ版のコードは v0.1.2 までの Git 履歴にあります。

## デスクトップ版からの変更

| 機能 | デスクトップ版 | Web 版 |
| --- | --- | --- |
| 録画 | FFmpeg gdigrab（対象一覧・範囲指定・赤枠） | ブラウザの画面共有（画面全体・ウィンドウ・タブをブラウザの画面で選択） |
| 音声 | WASAPI（マイク・PC 内部音声） | マイク、画面共有のシステム音声（Chrome / Edge、画面全体の共有時） |
| クリック強調 | 録画中にクリック位置を記録 | 非対応（既存のクリック記録の書き出しには対応） |
| 範囲を指定して録画 | 対応 | 非対応 |
| 書き出し | PC に導入した FFmpeg | ffmpeg.wasm（ブラウザ内、シングルスレッド） |
| 自動保存・復旧 | アプリのデータフォルダー | IndexedDB |
| 配布 | exe / msi インストーラー | Vercel で公開する Web ページ |

編集画面（タイムライン・注釈・音声・Undo / Redo など）と、プロジェクト JSON の形式は変更していません。

## 残る検証

- Windows 実機の Chrome / Edge での録画（MP4 形式で録画される経路）、PC 内部音声、「最前面に表示」の操作バー
- 長時間の録画・書き出し（メモリ使用量と処理時間）
- Vercel 上での動作
